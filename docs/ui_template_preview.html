📋 设计规范说明

🎨 配色方案

深色主题 + 高对比度强调色，适合长时间常驻屏幕

✨ 动画效果

• 角色浮动动画 (0.5s ease-in-out)
• 产出飘字动画 (0.8s ease-out)
• 卡片悬停变换 (0.2s)
• 连接指示器脉冲 (2s infinite)
• 收取按钮弹跳 (1s infinite)

📐 三种显示模式

• 横屏: 底部横条，动态场景，类似 Rusty's
• 竖屏: 经典窗口，480×640px
• 边栏: 极简侧边栏，200-280px

🎮 核心交互

• 点击角色卡片 → 展开详情浮窗
• 点击采集区域 → 打开区域详情
• 拖拽角色 → 切换工作区域
• Ctrl+M → 切换显示模式
