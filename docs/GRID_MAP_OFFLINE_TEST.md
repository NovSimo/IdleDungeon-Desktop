# 格子地图系统 - 离线测试版

## 快速开始

### 方法一：直接运行格子地图场景

1. 在 Godot 编辑器中打开项目
2. 打开 `scenes/grid/grid_game_screen.tscn` 场景
3. 按 F5 或点击"运行"按钮

### 方法二：通过主界面切换（待集成）

在 `main.tscn` 或 `game.tscn` 中添加按钮切换到格子地图模式。

## 操作指南

| 操作 | 说明 |
|------|------|
| 点击"🏗️ 建造" | 打开建造面板 |
| 选择建筑类型 | 开启建造预览 |
| 左键点击地图 | 放置建筑（预览模式下） |
| 右键点击 | 取消预览/关闭面板 |
| 滚轮滚动 | 横向滚动地图 |
| 点击建筑 | 查看建筑详情 |
| 点击"⬆️ 升级" | 消耗金币升级 |
| 点击"🛠️ 工作" | 分配角色开始生产 |
| 点击"🗑️ 拆除" | 拆除建筑 |
| 点击"👤 添加角色" | 在随机空格子添加角色 |
| 点击"🔄 重置" | 重置所有建筑和角色 |

## 离线模拟功能

当前版本实现了完整的离线模拟：
- 角色在建筑中工作时自动产出资源
- 资源实时累加并显示在底部状态栏
- 升级消耗金币系统
- 默认创建 4 个测试建筑 + 1 个角色
