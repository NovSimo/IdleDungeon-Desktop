# 悬浮地牢 — 主界面设计规范

> 版本: v1.0 | 日期: 2026-05-12
> 目标: 为客户端开发者提供可落地的主界面实现规范

---

## 一、设计总览

### 1.1 视觉风格

| 属性 | 设计 |
|------|------|
| **风格定位** | 暗紫黑像素复古风，带霓虹高光点缀 |
| **窗口规格** | 480×720px（可按比例缩放），透明悬浮窗 |
| **边框风格** | 1-2px 实线边框，圆角 6-12px，无渐变阴影 |
| **字体** | ZCOOL KuaiLe（标题/Logo） + Noto Sans SC（正文） |
| **图标** | Emoji 作为主要图标（统一 Unicode 方案），详见附录 |

### 1.2 布局结构

```
┌──────────────────────────────────┐  ← 窗口边框 2px #4a4a6e
│  顶部状态栏 (52px)                │  ← 连接指示 | 金币 | 收件 | 模式
├──────────────────────────────────┤
│  Tab标签栏 (44px)                │  ← 角色 | 经营 | 地牢 | 更多
├──────────────────────────────────┤
│                                  │
│  面板内容区 (560px, 可滚动)        │  ← 各 Tab 对应内容
│                                  │
│                                  │
│                                  │
│  [Toast 通知层 — 底部居中]         │  ← 操作反馈
└──────────────────────────────────┘
```

## 二、顶部状态栏（TopBar）

### 2.1 布局
```
[●连接] [💰 12,450 金币]        [📬 收取 badge] [完整]
```

### 2.2 元素规格

| 元素 | 节点类型 | 尺寸 | 说明 |
|------|----------|------|------|
| 连接指示器 | `ColorRect` | 10×10px 圆角 | 绿=已连接，红=断开，带脉冲动画 |
| 金币显示 | `HBoxContainer` | auto | 背景 #252540，边框 #b8960f，圆角 20px |
| 收取按钮 | `Button` | auto | badge 显示待领取数量，红底白字圆角 |
| 模式按钮 | `Button` | auto | 切换完整/紧凑/迷你/停靠模式 |

### 2.3 连接指示器动画
```gdscript
# 连接时脉冲动画（Godot 实现）
var pulse_tween := create_tween().set_loops()
pulse_tween.tween_property(dot, "modulate:a", 0.5, 1.0)
pulse_tween.tween_property(dot, "modulate:a", 1.0, 1.0)
```

## 四、角色面板（CharacterPanel）

### 4.1 布局
```
┌──────────────────────────────────┐
│ 工作槽位 (3个槽位指示器)          │
├──────────────────────────────────┤
│ 角色卡片 1 (工作中)               │
│ 角色卡片 2 (空闲+休息加成)        │
│ 角色卡片 3 (探险中)               │
│ ...                               │
└──────────────────────────────────┘
```

### 4.2 工作槽位指示器

- 3 个槽位横向排列（`HBoxContainer`）
- `locked` 状态: 虚线边框，opacity 0.5，显示解锁条件文字
- `occupied` 状态: 绿色边框，显示角色头像 + 操作图标 + 进度百分比
- 第3槽锁定条件: 酒馆 Lv.1

### 4.3 角色卡片（CharacterCard）

#### 卡片状态
| 状态 | 边框效果 | 左边缘条 | 说明 |
|------|----------|----------|------|
| `idle` | 普通灰紫 | 无 | 空闲，可安排工作 |
| `working` | 普通灰紫 | 3px 绿色 | 正在工作 |
| `exploring` | 普通灰紫 | 3px 橙色 | 正在地牢探险 |
| `selected` | 金色边框 + 光晕 | 保持 | 选中展开详情 |
| `fatigue_high` | 红色边框 | 保持 | 疲劳 >80% |

#### 卡片内容
```
┌──────────────────────────────────────┐
│ [头像44px] 名字 Lv.X    [工作][探险] │
│  职业·稀有度  [皮肤标签]              │
├──────────────────────────────────────┤
│ HP  ████████░░░░ 80/100              │
│ 疲劳 ███░░░░░░░░░ 30%                │
│ 进度 █████░░░░░░░ 50%  (工作中时显示) │
│ 状态 💤 空闲 45min  +10% (空闲时显示)  │
└──────────────────────────────────────┘
```

#### 头像背景渐变（按职业）
| 职业 | 渐变背景 |
|------|----------|
| 战士 | `#4a2a2a` → `#6b3a3a` |
| 法师 | `#2a2a6b` → `#3a3a8b` |
| 盗贼 | `#2a4a2a` → `#3a6a3a` |
| 治疗师 | `#2a4a4a` → `#3a7a7a` |
| 商人 | `#4a4a2a` → `#7a7a3a` |
| 矿工 | `#3a3a3a` → `#5a5a5a` |

## 五、经营管理面板（ManagementPanel）

### 5.1 布局
```
┌──────────────────────────────────┐
│ 采集区域选择器（操作Tab+区域列表） │
├──────────────────────────────────┤
│ 设施卡片 1 (伐木场 Lv.2)          │
│ 设施卡片 2 (锻造坊 Lv.1)          │
│ 设施卡片 3 (炼金台 未建造🔒)       │
├──────────────────────────────────┤
│ 工作队列                          │
│ 1.[角色][操作类型] [进度条] [×]   │
│ 2.[角色][操作类型] [--] [×]       │
│ + 添加工作                        │
└──────────────────────────────────┘
```

### 5.2 采集区域选择器

#### 操作 Tab（4个）
| 操作 | 图标 | 说明 |
|------|------|------|
| 采集 | 🌿 | 获取草药类原材料 |
| 伐木 | 🪓 | 获取木材类原材料 |
| 挖矿 | ⛏️ | 获取矿石类原材料 |
| 钓鱼 | 🎣 | 获取鱼类原材料 |

#### 区域列表
每条区域项：
```
Lv.X  区域名  [品质标签]
```
- 锁定区域: opacity 0.5，不可点击
- 选中区域: 边框 #ffd700，背景微金色
- 品质标签颜色对应品质颜色体系

### 5.3 设施卡片

| 状态 | 样式 | 按钮 |
|------|------|------|
| 已解锁 | 正常边框 | `升级`（绿色按钮） |
| 未建造 | opacity 0.6 | `建造`（橙色按钮） |
| 建造中 | 进度条替代按钮 | 无（显示进度） |

### 5.4 工作队列

- 每行: 序号 + 角色头像 + 操作名 + 区域/配方名 + 进度条 + 取消按钮
- 底部: `+ 添加工作` 虚线按钮
- 当前执行项: 进度条有颜色（绿色=采集，金色=加工）

### 8.1 按钮组件

| 类型 | 背景色 | 边框色 | 文字色 | 用途 |
|------|--------|--------|--------|------|
| `primary` | `#2d4a3e` | `#4ade80` | `#4ade80` | 确认/成功 |
| `secondary` | `#3a3a5e` | `#6b6b8e` | `#aaaaaa` | 取消/返回 |
| `warning` | `#4a3a2a` | `#ffa500` | `#ffa500` | 探险/危险 |

### 8.2 进度条

| 用途 | 填充色 |
|------|--------|
| HP | `#ff6b6b` |
| 疲劳 | `#ffa500` |
| 工作进度（采集） | `#4ade80` |
| 工作进度（加工） | `#ffd700` |
| 探险进度 | `#ffa500` |

- 位置: 面板底部居中
- 动画: 滑入 0.3s，停留 2s，滑出 0.3s

### 8.4 浮动面板（FloatingPanel）

- 边框: 2px `#ffd700`
- 背景: `#1a1a2e`
- 圆角: 12px
- 阴影: `Color(0,0,0,0.6)` 偏移 (0,8) 扩展 32

## 九、Godot 实现结构

### 9.1 场景层级
```
game.tscn
└── VBoxContainer
    ├── TopBar (HBoxContainer)
    │   ├── ConnectionIndicator (ColorRect)
    │   ├── CurrencyLabel (Label)
    │   ├── CollectButton (Button)
    │   └── ModeButton (Button)
    ├── TabContainer
    │   ├── CharacterPanel (character_panel.tscn)
    │   ├── ManagementPanel (management_panel.tscn)
    │   ├── DungeonPanel (dungeon_panel.tscn)
    │   └── MorePanel (more_panel.tscn)
    └── FloatingWindowManager (Node)
```

### 9.2 独立子场景
| 场景文件 | 说明 |
|----------|------|
| `character_card.tscn` | 单个角色卡片（含详情浮窗） |
| `facility_entry.tscn` | 单个设施条目 |
| `work_slot_indicator.tscn` | 工作槽位指示器 |
| `dungeon_card.tscn` | 单个地牢卡片 |
| `region_item.tscn` | 采集区域列表项 |

### 9.3 推荐的 AutoLoad（单例）
| 名称 | 职责 |
|------|------|
| `GameManager` | 全局游戏状态管理 |
| `NetworkManager` | WebSocket 连接与通信 |
| `EventBus` | 跨面板事件总线 |
| `AudioManager` | 音效播放 |
| `FloatingWindowManager` | 悬浮窗层级管理 |

### 9.4 关键信号（EventBus）
```gdscript
# 网络状态
signal network_status_changed(connected: bool)
# 金币变化
signal currency_changed(old: int, new: int)
# 玩家数据同步完成
signal player_state_synced(data: PlayerStateData)
# 角色状态变化
signal character_state_changed(character_id: String)
# 工作完成
signal work_completed(character_id: String, rewards: Array)
# 地牢探险完成
signal dungeon_exploration_completed(floor: int, rewards: Array)
```

## 十、交互动效清单

| 交互 | 动效 |
|------|------|
| Tab 切换 | 内容区淡入淡出 (200ms) |
| 角色卡片点击 | 边框高亮 + 缩放 0.98 (100ms) |
| 角色详情展开 | 从卡片底部滑出 (250ms ease-out) |
| 进度条更新 | 平滑过渡 (500ms linear) |

| Toast 消失 | 向上淡出 (300ms, delay 2s) |
| 收取按钮 badge | 数字跳动动画 |
| 连接指示器 | 脉冲光晕动画 (2s 循环) |
| 疲劳 >80% | 卡片边框红色脉冲 |
