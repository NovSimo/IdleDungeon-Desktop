# 悬浮地牢 — 模拟经营玩法设计文档

> 版本: v1.3 | 日期: 2026-05-11
> 定位: 悬浮桌面模拟经营 × 地牢探险挂机

---

## 一、设计总纲

### 1.1 核心循环

```
指派角色工作 → 离线挂机产出 → 收集资源 → 加工/强化/建造 → 角色变强 → 挑战更深层地牢
```

模拟经营与地牢探险形成双循环驱动：

- **经营循环**：采集 → 加工 → 建造/强化 → 解锁更高级设施 → 更高效的采集加工
- **探险循环**：派遣角色 → 探索地牢 → 获得稀有材料和新角色 → 反哺经营系统

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **挂机友好** | 玩家指派后离线也能产出，回来"收获"即可 |
| **三层产业链** | 采集(原材料) → 加工(半成品/成品) → 高级操作(强化/炼金/建造) |
| **职业差异化** | 不同职业在不同工作上有专精加成，角色分配有策略性 |
| **时间=价值** | 所有产出的底层货币是"时间"，越稀有的物品需要的投入时间越长 |
| **可扩展** | 资源类型、配方、工作类型均可后续追加，系统开放 |

### 1.3 工作分类总览

| 类别 | 操作 | 说明 |
|------|------|------|
| **采集** | 采集、伐木、挖矿、钓鱼 | 从自然获取原材料 |
| **加工** | 纺织、制作、冶炼、烹饪 | 将原材料加工为成品 |
| **高级** | 强化、炼金、建造 | 消耗成品产出高级效果 |

### 2.1 资源分级

| 品质 | 颜色标识 | 稀有度 | 获取途径 |

| 普通 (Common) | 白色 | 基础采集即可获得 | 采集 |
| 优良 (Fine) | 绿色 | 需要较高技能等级或中级设施 | 采集(高等级)、初级加工 |
| 稀有 (Rare) | 蓝色 | 需要高级设施或地牢掉落 | 加工、地牢 |
| 传说 (Legendary) | 橙色 | 仅地牢深层或炼金产出 | 地牢深处、炼金 |

### 3.2 采集区域系统

每种采集操作对应 **8 个不同等级的区域**，共 32 个区域。区域等级越高，产出越稀有，但采集时间越长、装备要求越高。

**每个区域属性**：
- **主产出**：区域的核心资源（必定获得）
- **副产出**：区域的额外资源（概率获得）
- **品质范围**：该区域可产出的最高品质
- **解锁条件**：技能等级 + 设施等级 + 地牢进度

### 3.3 单采与混合采集

玩家在每个区域可以选择两种采集模式：

| 维度 | 单采 (Focus) | 混合采集 (Mixed) |
|------|-------------|----------------|
| 主产出量 | 100% 基础产出 | 70% 基础产出 |
| 副产出量 | 不产出 | 按区域定义的副产出概率 |
| 采集速度 | 基础时长 ×0.85（快15%） | 基础时长 ×1.0 |
| 技能经验 | 1x 正常 | 1.2x（多20%经验） |
| 总价值/时间 | 1.0x 基准 | ~1.15x 基准 |

**单采产出公式**：

```
产出 = floor(基础主产出 × (1+技能加成) × (1+职业加成) × (1+装备加成) × (1+设施加成) × (1+休息加成) × 随机波动)
```

**混合采集产出公式**：

```
主产出 = floor(基础主产出 × 0.7 × (1+技能加成) × (1+职业加成) × (1+装备加成) × (1+设施加成) × (1+休息加成) × 随机波动)

副产出 = if randf() < 副产出概率 × (1+技能加成×0.5) × (1+装备加成×0.5):
           floor(副产出基础量 × (1+职业加成) × 随机波动)
         else: 0
```

**策略选择指南**：

| 场景 | 推荐模式 | 原因 |
|------|----------|------|
| 急需大量铁矿做铁锭 | 单采矿洞 | 主产出100%，速度+15%，集中获取 |
| 日常挂机过夜 | 混合采集 | 总价值+15%，经验+20%，省心 |
| 刷秘银矿（稀有副产物） | 混合深层矿脉 | 副产出含秘银，单采拿不到 |
| 升级采集技能 | 混合采集 | 经验+20%加速升级 |
| 做特定配方缺某一种材料 | 单采对应区域 | 精准获取需要的材料 |

#### 装备加成整合公式

**产出数量**：

```
最终产出 = floor(
    基础产出 × 模式系数(单采1.0/混合0.7)
    × (1 + 技能等级加成)
    × (1 + 职业加成)
    × (1 + 工具产出加成 + 服装产出加成 + 配件产出加成)
    × (1 + 设施加成)
    × (1 + 休息加成)
    × 随机波动
)
```

**品质概率**：

```
优良概率 = 基础概率 + 工具优良加成 + 服装品质加成 + 配件品质加成
稀有概率 = 基础概率 + 工具稀有加成 + 配件品质加成
```

**采集速度**：

```
实际时长 = 基础时长 × (1 - 速度加成合计) × 单采系数(0.85/1.0)
```

**疲劳增速**：

```
疲劳增加/分钟 = 1.0 × (1 - 疲劳减免合计)
```

### 3.5 品质判定

每次采集时，产出品质由技能等级和装备共同决定：

| 品质 | 触发条件 | 基础概率 |
|------|----------|----------|
| 普通 | 默认 | 100% |
| 优良 | 对应采集技能 ≥ Lv.3 | 基础 20% + (技能等级 - 3) × 5% + 装备优良加成 |
| 稀有 | 对应采集技能 ≥ Lv.6 | 基础 5% + (技能等级 - 6) × 2% + 装备稀有加成 |

**品质判定逻辑**：

```
if 技能等级 >= 6:
    稀有概率 = 0.05 + (技能等级 - 6) * 0.02 + 装备稀有加成
    if randf() < 稀有概率: 产出稀有品质
elif 技能等级 >= 3:
    优良概率 = 0.20 + (技能等级 - 3) * 0.05 + 装备优良加成
    if randf() < 优良概率: 产出优良品质
否则: 产出普通品质
```

| 操作 | 基础时长 | 基础产出价值 | 价值/分钟 |
|------|----------|------------|-----------|
| 采集 | 30s | 1~3 草药 ≈ 3 金币 | 6 金币 |
| 伐木 | 40s | 1~2 木材 ≈ 3 金币 | 4.5 金币 |
| 挖矿 | 50s | 1~2 铁矿 ≈ 4 金币 | 4.8 金币 |
| 钓鱼 | 45s | 1~3 鱼 ≈ 3 金币 | 4 金币 |
| 纺织 | 60s | 1 粗布 ≈ 6 金币 | 6 金币 |
| 制作 | 80s | 1 铁件 ≈ 8 金币 | 6 金币 |
| 冶炼 | 90s | 1 铁锭 ≈ 10 金币 | 6.7 金币 |
| 烹饪 | 50s | 1 烤鱼 ≈ 4 金币 | 4.8 金币 |

**设计目标**：加工链的每分钟价值略高于纯采集（约 1.2x~1.5x），鼓励玩家建立产业链而非只做原始采集。

### 8.2 产业链价值倍率

```
原材料 → 一级加工 → 二级加工 → 三级加工
  1x     →   1.5x    →   2.5x    →   4x
```

每一级加工消耗更多材料和时间，但产出价值倍率更高。这鼓励玩家：
1. 早期只能做纯采集（低价值但稳定）
2. 中期建立加工链（需要设施投入，但回报更高）
3. 后期进入强化/炼金（高投入高回报，需要地牢材料）

### 8.3 金币经济

| 金币来源 | 说明 |
|----------|------|
| 出售材料/成品 | 基础收入，商人角色 +20% 售价 |
| 地牢通关奖励 | 一次性大额奖励 |
| 设施被动产出出售 | 挂机收入 |

| 金币消耗 | 说明 |
|----------|------|
| 建造/升级设施 | 主要消耗 |
| 购买基础材料 | 应急补充（价格略高于自己采集） |

### 8.4 稀缺度设计

| 资源层级 | 获取方式 | 稀缺度 | 目的 |
|----------|----------|--------|------|
| 普通材料 | 采集 | 低 | 保证基础产出不卡壳 |
| 优良材料 | 高技能采集/加工 | 中 | 中期目标，驱动升级 |
| 稀有材料 | 高技能+高设施/地牢 | 高 | 后期追求，驱动深度游玩 |
| 传说物品 | 地牢深层/高级炼金 | 极高 | 终极目标，驱动探险 |

### 9.1 指派规则

- 每个角色同一时间只能执行一种工作
- 工作完成后，角色自动进入"空闲"状态
- 玩家可以为角色设置 **工作队列**（最多 5 个），完成一个自动接下一个
- 离线期间，服务端按队列持续执行

### 9.2 队列示例

```
矿工"铁锤" 的工作队列:
1. [挖矿] 铁矿 × 3  ← 当前执行中
2. [冶炼] 铁锭 × 2
3. [挖矿] 铁矿 × 3
4. [冶炼] 精钢锭 × 1
```

### 9.3 批量操作

- 同一种工作可以设置重复次数（1~99 次）
- 设置"循环"模式：完成指定次数后从头开始（直到手动停止或材料耗尽）

## 十、与地牢系统的联动

### 10.1 经营 → 地牢

- **装备强化**：强化后的装备提升角色地牢战斗力
- **药水补给**：出发前给角色配备药水
- **角色休息**：酒馆恢复角色生命后再出发

### 10.2 地牢 → 经营

- **稀有材料**：地牢掉落地图外稀有材料（如龙鳞、暗影精华）
- **新角色**：通关特定地牢解锁新角色
- **设施蓝图**：深层地牢掉落蓝图，解锁高级设施
- **金币**：通关奖励

### 10.3 资源互锁设计

```
经营系统提供: 强化材料、药水、装备 → 帮助地牢探险
地牢系统提供: 稀有材料、蓝图、新角色 → 帮助经营升级
```

两者形成正向循环，缺一不可。

```
4. 装备获取途径分离
   - 生活装备：加工制作、地牢掉落、商店购买
   - 战斗装备：地牢掉落、炼金制作（后续扩展）
```

## 十二、皮肤系统

### 12.1 概述

皮肤不仅是外观变化，更是**专精重定向**——同一个角色换不同皮肤后，擅长的工作类型会发生改变。这为游戏增加了策略深度：同一个战士，穿不同皮肤可以胜任完全不同的工作。

### 12.2 皮肤类型

| 皮肤 ID | 名称 | 主题风格 | 获取方式 | 稀有度 |
|---------|------|----------|----------|--------|
| `default` | 默认 | 基础职业装 | 角色自带 | - |
| `halloween` | 万圣节 | 暗影/亡灵/南瓜 | 万圣节活动 / 地牢暗影层掉落 | 稀有 |
| `christmas` | 圣诞 | 冰雪/礼物/驯鹿 | 圣诞活动 / 商店 500 金币 | 稀有 |

| `lunar` | 新春 | 中国风/龙/烟花 | 春节活动 / 商店 600 金币 | 稀有 |

### 12.3 皮肤专精偏移规则

1. **每个皮肤重新分配 2 个 +50% 专精位 + 2 个 +25% 次专精位**（与默认职业表同总量）
2. **偏移后总计加成值守恒** — 不会出现某个皮肤全面碾压
3. **每个皮肤至少有 1 个 -25% 惩罚位** — 有得必有失
4. **同职业不同皮肤的顶级专精不重叠** — 鼓励收集皮肤
5. **强化/炼金加成为小额附加值**，不参与±50%/±25% 主专精分配

### 12.4 皮肤切换规则

- 工作中不可切换皮肤（需先停止工作或等待完成）
- 切换皮肤不消耗任何资源
- 切换后立即生效新的专精加成
- 每个角色独立拥有自己的皮肤列表

## 十三、工作槽位系统

### 13.1 槽位规则

| 项目 | 设计 |
|------|------|
| 基础槽位数 | 3 个（同时最多 3 个角色工作） |
| 初始槽位 | 2 个 |
| 第 3 槽位解锁 | 酒馆 Lv.1 |
| 可扩展上限 | 后续版本可扩展到 4~5 个（通过特殊建筑/VIP） |
| 单角色约束 | 同一角色同一时间只能占 1 个槽位 |
| 多角色同操作 | 不同角色可以同时做同一种操作（如 2 人同时挖矿） |
| 槽位释放 | 工作完成且队列为空时自动释放 |

### 13.2 空闲角色机制

闲置角色不是完全没用——他们获得以下被动效果：

| 机制 | 说明 | 解锁条件 |
|------|------|----------|
| **休息恢复** | 自动恢复生命值（1%/分钟） | 默认 |
| **休息加成** | 连续空闲 ≥30 分钟，下次工作产出 +10%（最多 +30%，即 90 分钟） | 默认 |
| **被动训练** | 最低技能等级缓慢提升（每 8 小时 +0.1 级） | 酒馆 Lv.3 |
| **地牢待命** | 空闲角色可被指派到地牢探险（不占用工作槽） | 地牢解锁 |

**休息加成叠加速率**：

| 空闲时长 | 产出加成 |
|----------|----------|
| 0~29 分钟 | 0% |
| 30~59 分钟 | +10% |
| 60~89 分钟 | +20% |
| 90 分钟+ | +30%（上限） |

> 休息加成在角色开始工作后立即重置为 0，需要重新积累。

### 13.3 疲劳系统

| 项目 | 设计 |
|------|------|
| 疲劳范围 | 0~100 |

| 强制休息 | 疲劳达 100 时自动停止工作，需休息至 80 以下才能重新工作 |

## 十四、UI界面设计

### 14.1 设计风格：像素复古风

| 属性 | 设计 |
|------|------|
| **视觉风格** | 像素复古风，低多边形/锐利边缘，参考经典地牢爬虫游戏 |
