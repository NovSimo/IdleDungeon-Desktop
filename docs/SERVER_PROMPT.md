# IdleDungeon 服务器开发提示文本

## 项目概述

**项目名**：悬浮地牢（IdleDungeonDesktop）
**类型**：悬浮桌面模拟经营 × 地牢探险挂机游戏
**架构**：客户端-服务端分离
  - **客户端**：Godot 4.6，负责展示层（由另一个AI开发）
  - **服务端**：执行所有挂机计算逻辑，离线也能运行
  - **通信**：WebSocket（ws:// / wss://）

---

## 核心功能

### 1. 工作系统（最重要）
- 指派角色到工作槽位执行采集/加工等操作
- 支持**离线挂机**：玩家离线时服务端持续计算，回来后推送结果
- 工作队列：每个角色可设置最多5个工作的队列，完成自动接下一个

### 2. 采集系统
- 4种采集操作：采集(gather)、伐木(chop)、挖矿(mine)、钓鱼(fish)
- 每种操作8个区域（等级1~8），共32个区域
- 两种采集模式：
  - **单采(Focus)**：主产出100%，速度快15%
  - **混合采集(Mixed)**：主产出70%+副产出，总价值+15%，经验+20%

### 3. 加工系统
- 4种加工操作：纺织(weave)、制作(craft)、冶炼(smelt)、烹饪(cook)
- 按配方消耗材料产出加工品
- 加工有成功率，失败消耗一半材料

### 4. 强化系统（核心功能）
- **核心定位**：提升装备等级（+1 → +10）
- 消耗：铁锭、铁件、精钢锭、精工件、秘银锭、秘银件、强化卷轴
- 成功率递减（100% → 2%），失败后果递增（无→降级→归零）

### 5. 炼金系统（核心功能）
- **核心定位**：材料互相转换
- 提炼精华：原材料 → 精华（风/火/水/土）
- 合成药水：精华+材料 → 药水（生命/力量/幸运）
- 制作卷轴和蓝图

### 6. 角色系统
- 6种职业：战士、法师、盗贼、治疗师、商人、矿工
- 每个职业有不同的工作专精加成
- 最多12个角色，初始4个
- 3个工作槽位（初始2个，酒馆解锁第3个）
- 疲劳系统：工作增加疲劳，高疲劳降产出，100强制休息

### 7. 皮肤系统
- 6种皮肤：Default/Halloween/Christmas/Swimsuit/Lunar/Cyber
- **核心设计**：皮肤改变专精方向（不只是外观）
- 每个皮肤重新分配职业加成，可切换

### 8. 装备系统（两套）
- **生活装备**：工具/服装/配件，影响工作效率
- **战斗装备**：头/身/腿/鞋/手套/主手/副手/翅膀/项链/耳环×2/戒指×2
  - **战斗功能暂不实现**，只预留数据结构

### 9. 设施系统
- 10种设施：工坊、锻造坊、厨房、炼金台、药园、伐木场、矿井、鱼塘、酒馆、仓库
- 可升级（1~10级）
- 部分设施有被动产出

## 离线挂机关键逻辑

服务端需要维护：
1. **玩家状态**：角色列表、库存、设施、疲劳值
2. **工作进度**：每个角色的当前工作、完成时间
3. **时间同步**：计算玩家离线期间的所有产出
4. **推送机制**：玩家上线时推送离线期间的完整结果

## 开发建议

1. 先实现**采集和工作系统**，这是游戏核心循环
2. 然后实现**加工系统**，建立产业链
3. 再实现**强化和炼金**，作为进阶内容
4. 角色、皮肤、装备系统作为辅助模块
5. 最后接入WebSocket通信，对接客户端
