# 悬浮地牢 — Rusty 风格重新设计文档

> 版本: v2.0 | 日期: 2026-05-12
> 参考: Rusty's Retirement 设计理念
> 定位: 桌面常驻挂机游戏（采集经营 × 地牢探险）

---

## 一、核心理念转变

### 1.1 Rusty's 的精髓

| Rusty's 特色 | 悬浮地牢的借鉴 |
|--------------|----------------|
| 屏幕边缘常驻 | 支持横屏/竖屏双模式，可放置屏幕边缘 |
| 几乎不干扰正常工作 | 专注模式 + 界面缩放 |
| 自动挂机循环 | 全自动资源循环，角色自动轮换 |
| 简约但有深度 | 主界面极简，详细操作在浮窗中 |
| 竖屏边栏模式 | 支持竖屏放置于屏幕侧边 |

### 1.2 新设计总纲

```
自动循环: 角色工作 → 产出资源 → 自动加工 → 自动强化 → 地牢探险
玩家操作: 初始配置（谁去哪做什么）→ 偶尔收取 → 升级设施
核心乐趣: 看着角色们自动工作 + 探索地牢惊喜 + 角色成长
```

### 1.3 设计原则

| 原则 | 说明 |
|------|------|
| **常驻优先** | 游戏放在屏幕边缘，不遮挡主要工作 |
| **自动为王** | 初始配置后尽量自动运行，减少点击需求 |
| **信息分层** | 主界面只显示"状态总览"，详情在浮窗中 |
| **节奏可控** | 专注模式可减慢游戏节奏 |
| **成长可见** | 每次打开都有可感知的进度 |

## 三、自动循环系统

### 3.1 全自动工作流

```
┌─────────────────────────────────────────────────────────────────┐
│                        自动循环示意                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   [角色工作] ──产出──→ [自动入库] ──检测──→ [自动加工队列]       │
│       ↑                                     │                   │
│       │                                     ↓                   │
│   [疲劳休息] ←──自动轮换── [加工完成] ──→ [自动强化队列]         │
│                                               │                 │
│                                               ↓                 │
│                                          [地牢探险]             │
│                                               │                 │
│                                               ↓                 │
│                                          [收获+奖励] ──→ 循环    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 自动规则配置

| 功能 | 说明 | 可配置 |
|------|------|--------|
| **自动采集** | 角色自动前往指定区域工作 | ✅ |
| **自动加工** | 原材料足够时自动开始加工 | ✅ |
| **自动强化** | 有材料时自动强化角色/装备 | ✅ |
| **自动探险** | 角色体力/状态满足时自动探索 | ✅ |
| **自动休息** | 疲劳值 > 70 时自动换下 | ✅ |
| **自动轮换** | 空闲角色自动顶替疲劳角色 | ✅ |

### 3.3 规则预设

| 预设 | 描述 | 适用场景 |
|------|------|----------|
| **挂机模式** | 全部自动，适合长时间离开 | 上班/睡觉 |
| **半自动** | 自动采集加工，手动探险 | 日常休闲 |
| **手动模式** | 全部手动，完全控制 | 研究策略 |
| **专注模式** | 减慢节奏，减少弹窗 | 需要工作时 |

## 五、核心玩法循环

### 5.1 经营循环（Rusty's 风格）

```
采集原料 ──→ 加工成品 ──→ 强化角色/装备 ──→ 效率提升 ──→ 更深地牢
    ↑              │              │
    └────── 产出金币 ←───────────┘
```

**简化版**：
1. **配置角色** → 分配到 4 大采集区域（草地/森林/矿山/湖泊）
2. **自动产出** → 每隔一段时间产出资源
3. **自动加工** → 原材料积累后自动加工
4. **升级设施** → 用金币/资源升级加工设施
5. **效率循环** → 效率越高，产出越快

### 5.2 地牢循环

```
角色配置 ──→ 进入地牢 ──→ 自动战斗/探索 ──→ 获得奖励 ──→ 角色成长
    ↑                                                     │
    └────────────────── 角色变强 ←───────────────────────┘
```

**简化版**：
1. **指派探险队** → 选择 1-3 名角色
2. **自动探索** → 角色在地牢中自动战斗/搜刮
3. **实时进度** → 可查看探险进度和预估奖励
4. **返回收获** → 探险结束自动收获战利品
5. **角色升级** → 获得经验值，角色成长

### 5.3 双循环驱动

```
经营系统产出: 强化石/药水/装备 → 提升探险效率
地牢系统产出: 稀有材料/新角色 → 解锁高级经营内容
```

## 九、界面模式对比

### 9.1 三种模式总览

| 特性 | 横屏模式 | 竖屏模式 | 边栏模式 |
|------|----------|----------|----------|
| **外观** | 类似 Rusty's | 传统窗口 | 窄边栏 |
| **信息量** | 精简 | 适中 | 极简 |
| **占用空间** | 底部横条 | 角落区域 | 边缘侧边 |
| **适合场景** | 全屏工作 | 多任务 | 极简主义 |
| **切换方式** | 拖拽边缘/快捷键 | 窗口模式切换 | 拖拽到边缘 |

### 9.2 模式选择建议

| 用户场景 | 推荐模式 |
|----------|----------|
| 程序员/设计师 | 边栏模式（极简） |
| 文员/办公 | 横屏模式（底部常驻） |
| 游戏玩家 | 竖屏模式（详细信息） |
| 睡觉挂机 | 最小化/托盘 |
