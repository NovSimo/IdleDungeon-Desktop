组件说明

所有组件基于 Godot 4.6 的 Control 节点实现。建议将各面板拆分独立场景：CharacterPanel、ManagementPanel、DungeonPanel、MorePanel，通过 TabContainer 组合。角色卡片浮动详情面板作为独立子场景 CharacterDetailPopup，点击角色卡片时实例化并挂载到 FloatingWindowManager。

窗口背景使用 Godot 的 StyleBoxFlat 自定义样式，避免使用 NinePatch 纹理。
