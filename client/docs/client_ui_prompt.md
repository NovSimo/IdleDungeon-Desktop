## 一、设计理念总纲

### 1.1 核心理念

**像 Rusty's Retirement 一样**：游戏放置在屏幕边缘，不干扰正常工作，同时享受角色自动工作的乐趣。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **常驻优先** | 支持横屏/竖屏/边栏三种模式，可放屏幕边缘 |
| **自动为王** | 配置一次，角色自动循环工作，减少点击 |
| **信息分层** | 主界面极简，详情在浮窗中 |
| **视觉反馈** | 角色动画、产出飘字、状态光效 |
| **可交互** | 点击角色/区域可切换配置 |

## 三、动态采集场景（核心视觉）

### 3.1 场景布局

```
┌─────────────────────────────────────────────────────────────────┐
│                         天空背景渐变                               │
│                                                                  │
│   🌲           🌳      🌲              ← 背景树木装饰             │
│                                                                  │
│   🪨                                🪨  ← 岩石装饰                │
│                                                                  │
│  ┌草─┐  ┌木─┐  ┌矿─┐  ┌渔─┐          ← 采集区域（虚线框）       │
│  │药 │  │木 │  │区 │  │区 │                                    │
│  │区 │  │区 │  │   │  │   │                                    │
│  └───┘  └───┘  └───┘  └───┘                                    │
│ ═══════════════════════════════════════════════════════════════ │
│                      草地/地面渐变                                │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 角色行为

| 行为 | 说明 |
|------|------|
| **随机移动** | 角色在自己的区域内随机选择一个位置 |
| **平滑动画** | 移动时使用 0.5s ease-in-out 过渡 |
| **到达采集** | 到达位置后播放上下浮动动画（0.3s） |
| **产出飘字** | 采集时显示 `🌿+1` 之类的飘字动画 |

### 3.3 采集区域定义

| 区域 | 位置 | 边框颜色 | 角色 |
|------|------|----------|------|
| 草药区 | 左侧 10-20% | #4ade80 | 🧙 艾伦 |
| 伐木区 | 左侧 30-40% | #8b5a2b | 🧝 贝拉 |
| 矿区 | 中间 50-60% | #8888aa | ⛏️ 伊凡 |
| 渔区 | 右侧 70-80% | #60a5fa | 🎣 汪酱 |

### 3.4 产出飘字动画

```css
@keyframes popUp {
    0%   { opacity: 0; transform: translateY(10px) scale(0.8); }
    20%  { opacity: 1; transform: translateY(0) scale(1.1); }
    100% { opacity: 0; transform: translateY(-40px) scale(1); }
}
/* 持续时间: 800ms */
```

```gdscript
#   text = "🌿+1"
#   modulate = Color(0.3, 0.9, 0.5) # 绿色
#   添加 Tween 动画:
#     - 0ms: position.y += 0, modulate.a = 0
#     - 100ms: modulate.a = 1
#     - 800ms: position.y -= 40, modulate.a = 0
#   动画结束后自动删除节点
```

## 八、动画清单

### 8.1 角色动画

| 动画 | 属性 | 参数 |
|------|------|------|
| 浮动 | modulate.y | ±3px, 0.5s |
