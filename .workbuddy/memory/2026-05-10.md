# 2026-05-10 工作记录

## 项目：IdleDungeonDesktop — 悬浮桌面模拟经营+地牢探险挂机游戏

### 完成内容
- 搭建 Godot 4 完整项目结构（project.godot + 目录体系）
- 实现 4 个 Autoload：EventBus（信号总线）、GameManager（游戏状态）、NetworkManager（网络同步）、AudioManager（音频）
- 实现数据模型层：PlayerStateData、CharacterData、WorkResultData、DungeonRunResult、FacilityState
- 实现 4 个核心组件：HealthComponent、WorkComponent、InventoryComponent、StatsComponent
- 实现 CharacterBase 角色基类（组合模式）
- 实现 WorkManager（经营管理）和 DungeonManager（地牢探险回放）
- 实现 FloatingWindowManager（悬浮桌面窗口：置顶/透明/点击穿透/多模式切换）
- 实现 UI 展示层：CharacterPanel、ManagementPanel、FacilityEntry、DungeonPanel、Main
- 创建工具类 GameUtils

### 架构决策
- 客户端纯展示，所有计算逻辑在服务端，客户端通过 NetworkManager 的 WebSocket 接收推送
- EventBus 仅用于跨场景事件，场景内通信使用组件信号直接连接
- 全量静态类型 GDScript 2.0，启用 strict 模式警告
- 组件组合模式替代继承，每个组件 < 200 行

## 2026-05-11 升级记录

### 项目从 Godot 4.3 升级到 Godot 4.6

#### 修改内容
1. **project.godot**: `config/features` 从 `"4.3"` 更新为 `"4.6"`
2. **network_manager.gd**: WebSocket 连接 URL 从 `http://`/`https://` 修正为 `ws://`/`wss://`（4.6 正确前缀）
3. **character_base.gd**: 所有动画名从 String 字面量改为 StringName 字面量（`"idle"` → `&"idle"`），适配 4.6 AnimationPlayer 属性 String→StringName 变更
4. **dungeon_panel.gd**: 同上，动画名改为 StringName 字面量
5. **floating_window_manager.gd**: 添加 4.6 兼容性注释，修正枚举循环的类型转换

#### 4.3→4.6 关键变更点（本项目涉及的）
- AnimationPlayer: assigned_animation/autoplay/current_animation 从 String → StringName
- WebSocket URL 须用 ws:// 或 wss:// 前缀
- DisplayServer API 无破坏性变更
- 本项目是 2D，不受 3D 物理引擎默认切换到 Jolt 的影响
