## Bug 修复
1. **GatherSystem.js 技能判定 bug**: `calculateGatherOutput` 中用 `=== 'herb_common'` 只匹配了草药初级，修复为使用已有的 `getOpFromRegion()` 函数
2. **Character.js 序列化 bug**: `toJSON()` 方法直接序列化了 `currentWork`，当其中包含 Timer 对象时导致 `Converting circular structure to JSON` 错误。修复为序列化前移除 `_timeout`
3. **GameManager.js Timer 管理 bug**: `_timeout` 同时存在 `char.currentWork._timeout` 和 `this._timers` 两处，导致序列化失败。统一改为只存在 `this._timers` 中
4. **index.js API 参数提取不统一**: `start_work` 从 `msg.data` 提取参数，`collect_work` 从顶层 `msg.charId` 提取。新增 `extract()` 函数统一兼容两种格式（优先 `msg.data`，回退顶层）

## 当前 API 协议
所有请求参数统一用 `data` 字段传递：
- `create_player`: `{ action, playerId }`
- `start_work`: `{ action, playerId, data: { charId, operation, targetId, mode? } }`
- `collect_work`: `{ action, playerId, data: { charId } }`
- `get_status`: `{ action, playerId }`
- `set_skin`: `{ action, playerId, data: { charId, skinId } }`
