## Admin 后台（16:52）

### 文件结构
- `server/admin_server/src/index.js` — Admin WS 服务（8081）
- `server/admin_server/src/playerStore.js` — 玩家数据读写（直接操作 JSON）
- `server/admin_server/src/admin_panel.html` — 后台管理 HTML 面板
- `server/admin_server/admin_pass.txt` — 管理员密码文件

### 启动方式
```
cd server/admin_server && node src/index.js
# 后台面板: http://localhost:8081
# Admin WS : ws://localhost:8081
# 默认密码 : admin123
```

### Admin API 接口（需先 admin_login）
- `admin_login` — 登录（密码在 admin_pass.txt）
- `admin_list_players` — 所有玩家摘要列表
- `admin_stats` — 数据统计（总玩家/金币/角色）
- `admin_get_player` — 玩家完整数据
- `admin_give_item` — 加/扣物品（count 正负）
- `admin_set_gold` — 设置金币
- `admin_set_fatigue` — 设置角色疲劳值
- `admin_set_hp` — 设置角色 HP
- `admin_force_work` — 强制完成工作（不发奖励）
- `admin_cancel_work` — 取消工作
- `admin_delete_player` — 删除玩家存档
